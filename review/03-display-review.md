# 展示方案评审记录

## 评审目标

确认页面不是原始数据表的简单堆叠，而是围绕不同角色的管理问题组织信息。

## 核心结论

### Executive Dashboard

回答公司整体健康度、产品 Roadmap、项目延期、高风险和严重问题。

### Product Dashboard

回答产品状态、生命周期、需求完成、验证、版本和 Release 状态。

### Project Dashboard

回答项目进度、计划偏差、里程碑、依赖、风险、Issue 和 Change。

### Requirement / Verification

回答产品是否做了正确的东西，以及是否被充分验证。

### Risk / Issue / Change

回答当前最大的异常是什么，以及变化会造成什么影响。

### Execution Board

回答工程师现在做什么、什么任务即将到期、什么任务被阻塞。

## 展示原则

- 总览到细节逐级下钻。
- 异常优先。
- 趋势和状态优先于原始字段。
- 所有指标可追溯到数据源。
- 页面按角色提供不同的信息密度。
